# Kleari 0.1.0-beta.1

> **Installing for the first time, or on a new Mac?** Read
> [Read me before you install](../install.md#read-me-before-you-install) first. macOS warns you
> the first time you open Kleari: choose **Done** (never **Move to Trash**), then **Open
> Anyway** in System Settings › Privacy & Security.

The first beta of Kleari: keep your Mac clean and fast, on your Mac only. It finds space you
can reclaim, moves it to a quarantine you can undo, shows what your Mac is doing, tidies
developer caches and makes a mouse work your way. No account, no telemetry, nothing sent.

**Requires** a Mac with Apple silicon and macOS 14 or later.

## Install

Download `Kleari_0.1.0-beta.1_aarch64.dmg` below, open it and drag Kleari into Applications.
Open it, and confirm **Open Anyway** as in the guide above. Later updates install from inside
Kleari (Settings › About). As a beta, it gets the next betas automatically; turn off **Beta
updates** there if you'd rather wait for stable releases.

## What's in it

- **Cleanup** scans that only read, explained findings, and moves only what you approve, into
  quarantine. Optional scheduled scans.
- **Quarantine** with restore (never overwriting) and a separately confirmed permanent delete.
- **Storage**, **System**, **Processes** and **Developer** pages; System and Processes keep
  their readings going while Kleari is open.
- **Mouse:** classic wheel direction for a mouse only, speed, smooth scrolling, button
  actions, media keys and combinations (left or right click included).
- A **menu-bar** panel, an **Activity** log, signed in-app **updates** with an optional beta
  channel, and **Uninstall**.

The full list is in the [changelog](../../CHANGELOG.md).

## Known limitations

- Kleari isn't notarised by Apple, so macOS asks you to allow it the first time.
- Apple's Magic Mouse scrolls like a trackpad, so it keeps the trackpad's direction.
- A recorded shortcut uses the key's position on a US keyboard layout.
- Mission Control and Space switching use macOS's own keyboard shortcuts, which must be on in
  System Settings › Keyboard › Keyboard Shortcuts.
- Mouse settings work only while Kleari is running, and need Accessibility allowed.
