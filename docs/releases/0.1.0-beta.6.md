# Kleari 0.1.0-beta.6

> **Installing for the first time, or on a new Mac?** Read
> [Read me before you install](../install.md#read-me-before-you-install) first. macOS warns you
> the first time you open Kleari: choose **Done** (never **Move to Trash**), then **Open
> Anyway** in System Settings › Privacy & Security.

The sixth beta of Kleari is a small update that fixes how Kleari restarts after an update.
Kleari is free, open-source software provided as is, and it only acts on what you approve.
Everything happens on your Mac: no account, no telemetry, and the only thing that goes online
is the update check.

**Requires** a Mac with Apple silicon and macOS 14 or later.

## Install or update

If you have an earlier beta, Kleari offers this update in Settings › About (or when it opens).
Otherwise download `Kleari_0.1.0-beta.6_aarch64.dmg` below, open it and drag Kleari into
Applications.

Coming from beta 4 or 5, you keep your permissions. Coming from beta 3 or older, see
[After updating from beta 3 or older](../install.md#after-updating-from-beta-3-or-older).

## Fixed

- **Updates:** after Install and restart, the new version opens in Kleari's icon kept in the
  Dock instead of a second icon beside it. Kleari now quits first and opens the new version
  once it has gone, rather than starting it alongside.

  The restart is done by the version you are updating *from*, so updating to this beta from
  an earlier one can still show a second Dock icon once. Quit Kleari and open it from the
  Dock to clear it. Updates from this beta onwards open in the kept icon.

The full list is in the [changelog](../../CHANGELOG.md).

## Known limitations

- Kleari isn't notarised by Apple, so macOS asks you to allow it the first time.
- The Trash tab and Put Back need Full Disk Access.
- Caches of editors kept in Application Support (such as Cursor's) aren't offered: Kleari
  never touches Application Support for app caches.
- The processor's temperature and the fans are read through interfaces Apple doesn't
  document; a macOS update could stop them working.
- Alert thresholds are fixed, and Kleari can't tell when an app has stopped responding.
